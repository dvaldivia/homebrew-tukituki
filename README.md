# homebrew-tukituki (archived)

This tap is no longer updated. The `tukituki` formula moved to the shared
[dvaldivia/homebrew-dvaldivia](https://github.com/dvaldivia/homebrew-dvaldivia) tap.

To switch:

```sh
brew uninstall tukituki
brew untap dvaldivia/tukituki
brew install dvaldivia/dvaldivia/tukituki
```
